## 1. 현재 기준 모델: R4

- **구성:** ConvNeXt-T(384 미세조정 가중치)에서 stride 16과 32 특징을 쓰고, 마스크 풀링 0.5×(평균+최대) 뒤에 Linear(27)를 붙였다. 파라미터는 27.85M이다.
- **학습:** BCE + FashionFormer R50 증류(α 0.5, shift 0.3), EMA 0.9995, 18 epoch, 짧은 변 400~800, Crop 없음.
- **holdout(임계값 0.4):** 0.871 / 0.799 / 0.872
- **val:** 0.876 / 0.738 / 0.879
- **micro AP:** holdout 0.943, val 0.949
- **예시 30장(진단):** micro 0.647, 정밀도 0.863, 재현율 0.517, 군중 재현율 0.414
- **seed:** 1개(42)

## 4. 판정 규칙 (G1, 이후 모든 실험에 적용)

1. **기법 효과(순위 품질):** holdout과 val의 micro AP와 macro AP를 쌍 부트스트랩 95% 구간으로 본다. 두 데이터 모두에서 같은 방향으로 유의할 때만 "효과 있음"이라고 한다.
2. **운영 성능(F1):** 임계값은 holdout macro F1로 고른다(지금 규칙 유지). F1 차이는 보조로 보고하고, AP와 방향이 다르면 "보정 차이"로 기록한다.
3. **seed:** 차이가 R4의 seed 간 차이(G2로 측정)보다 작으면 결론을 내지 않는다.
4. **군중:** G5 데이터가 생기면 군중 재현율과 AP를 별도로 보고한다. 테스트 예시는 계속 진단에만 쓴다.
