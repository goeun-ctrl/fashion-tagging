# 기법 효과 지도 (2026-11-14, 5번)

지금까지 쓴 기법을 하나씩 정리한다. 각 기법이 무엇을 하는지, 효과를 어떤 비교로 쟀는지, 실제로 효과가 있었는지를 적었다.
목적은 발표 준비가 아니라 **우리가 쓴 기법의 효과를 제대로 아는 것**이다.

## 측정 기준

- **비교 쌍:** 설정을 하나만 바꾼 두 실행. 두 실행의 `config.json`을 직접 비교해서 확인했다.
- **지표:** 임계값과 무관한 지표를 쓴다.
  - **micro AP:** 모든 칸을 합쳐서 계산한 AP
  - **순위 점수:** 옷 하나하나가 같은 클래스 음성 사진의 몇 %보다 높은 점수를 받는지 (×100)
  - 순위 점수는 옷 면적(Fashionpedia 주석)으로 나눠 본다. 작은 옷은 면적 0.5% 미만, 큰 옷은 8% 이상이다.
- **구간:** 이미지 단위 쌍 부트스트랩 95%. ★는 holdout과 val **둘 다에서** 유의하다는 뜻이다.
- **seed 잡음:** 같은 설정에서 seed만 바꾼 두 쌍을 쟀다.
  - micro AP 차이: |0.0005~0.0015|, 유의하지 않음
  - 순위 점수 차이: 대부분 ±0.1 이내
  - macro AP 차이: 최대 0.017까지 흔들림
  - **그래서 macro AP와 macro F1의 작은 차이로는 결론을 내지 않는다.**
- 테스트 데이터는 쓰지 않았다. 원본 로그: 서버 `logs/why_all.txt`, `why_area.txt`, `why_area2.txt`, `why_kd.txt`, `ap_cmp.txt`

## 3. 이 정리로 바뀐 이해

1. **실제로 효과가 확인된 것은 네 가지다.** 고해상도, 증류, stride 16 + GAP·GMP(그중 최대 풀링이 작은 옷에 기여), 960 해상도다. 나머지는 대부분 순위에 영향이 없거나 해롭다.
2. **F1 차이의 상당수는 "보정" 차이였다.** GMP만, 800 고정, 의사 라벨의 F1 하락은 모두 순위 품질 변화 없이 임계값과 확률 분포만 달라진 결과다. F1만 보면 기법 효과를 잘못 읽는다.
3. **이전 결론 중 두 개를 정정한다.**
   - "800 위는 효과 없음" → micro AP 기준 960이 두 데이터 모두에서 조금 낫다(+0.003 / +0.004).
   - "ASL이 BCE보다 낫다"는 전제 → 고해상도와 증류 조건에서는 차이가 없다.
4. **해로운 기법은 공통점이 있다.** 모자이크와 마스크 지도는 모두 **큰 옷**에서 손해를 본다. 이미지를 작게 쪼개거나 칸 단위 판단을 강요하면, 옷 전체를 보는 판단이 약해진다는 가설로 묶인다.
5. **효과를 모르는 채 쓰고 있는 기법이 많다.** EMA, 학습률 설정, stride 16 단독 효과, 최종 조합의 각 증강이 그렇다. R4에 들어 있는 것 중에도 EMA와 학습 설정은 고해상도에서 단독으로 확인한 적이 없다.
