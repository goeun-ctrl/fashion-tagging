# 재설계 B 결과 정리 (2026-11-22 ~ 11-25)

구조와 확정값: [`재설계B_구현계획.md`](재설계B_구현계획.md). 원본 로그·큐·런 기록: [`experiments/role5_segb/`](../../experiments/role5_segb/).
모델 가중치: GitHub Release `segb-b24-s42` (24 epoch 4개, 런마다 zip).

## 0. 한 줄 요약

- **최종 B 후보 = `B24_base`** (분할 감독 UPerNet, ConvNeXt-T DINOv3, 24 epoch, 짧은 실험의 기본값 그대로).
- 최종 CNN(`R5_bce_kd_cnxtdv3_lr3e5_s42`, 800 no flip) 대비: **위치 크게 개선, 헷갈리는 그룹 같거나 조금 개선, macro AP 개선, micro AP −0.005(허용선 −0.03 안)**.
  남은 약점은 **작은 물체 recall**과 **군중(crowd) 사진**.
- 6 epoch에서 이득이 있던 영역 일관성 손실(rc)과 λ=2는 **24 epoch에서는 이득이 없었다**.

## 1. 판정 규칙 (사용자 결정, 2026-11-23)

1. 자동 탈락: 위치 `loc_topk` ★ 하락(holdout 또는 val), 또는 micro AP가 기준보다 0.03 넘게 하락.
2. 위치를 못 잰 런은 보류.
3. 나머지는 **검수 대상**. 헷갈리는 그룹 AP는 사람이 판단한다.
   그룹: 상의 [0–5, 9] / 하의+원피스 [6, 7, 8, 10, 11] / 머리 [14, 15] / 다리 [21, 22] / 목 [16, 25].
4. 참고만: crowd AP, small_recall, loc_topk_small.

★ = bootstrap 1,000회 95% 구간이 0을 포함하지 않음. 임계값은 holdout에서만 고른다. val은 확인용.
test_public · examples_labeled · Fashionpedia val2020은 학습·라벨·임계값·선택·증강에 쓰지 않는다.

## 4. 겹쳐 입은 옷(상의) 분석 — 모두 분석 전용, 학습·선택에 쓰지 않음

| 분석 | 방법 | 결과 | 결론 |
|---|---|---|---|
| 원인 (가/나) | CNN은 맞고 B만 틀린 상의 140장, 지는 클래스의 GT 마스크 안을 봄 | 마스크 안 옷 확률 0.87인데 **정답 클래스 몫 0.29** (86%가 0.5 미만) | 칸 단위로 한 벌이 여러 클래스로 갈림 (나) |
| A안 사후 투표 | 옷 영역 안 클래스 몫으로 다시 점수 | 겹친 상의 정답률 0.72 → 0.52 | 기각 (안쪽 옷이 지워짐) |
| rc 손실 후 재분석 | rc01 / rc03 / rc1 | 틀린 장수 140 → 117 / 106 / 128, 정답 몫 0.28 / 0.31 / 0.33 | 순위는 조금 나아지나 갈림 자체는 그대로 |
| 완벽 마스크 상한 | GT 마스크를 클래스 정보 없이 영역으로만 사용 | 상의 AP +0.02~0.03, 겹친 상의 정답률 +0.01~0.02 | 마스크(SAM 등)로 얻을 수 있는 최대치가 작음 |

## 5. 재계산 차이 (Mac 재계산 vs 서버 저장 예측)

서버 저장 예측과 Mac에서 다시 계산한 점수가 일부 사진에서 최대 0.4~0.5 달랐다. 원인:
1. **Mac GPU(MPS) 계산 오차** (주원인). 같은 입력에서 MPS와 CPU가 최대 0.18 차이, CPU는 서버와 거의 같다.
2. **패딩 크기**: 서버 평가는 고정 캔버스(짧은 변 800, 800×1344)에 패딩한다. 디코더 GroupNorm과 PPM 전역 평균이 패딩 칸까지 포함한다.

서버 저장 예측과 판정은 정상이다. Mac 분석(4장)은 방식끼리 같은 지도로 비교했고 재계산 AP도 서버와 거의 같아 결론은 그대로다.
**최종 추론은 학습과 같은 고정 캔버스로, CUDA 또는 CPU에서 한다(MPS 금지).**
참고: 위치 지표에서 CNN 쪽(Grad-CAM)과 S6 런은 Mac MPS로, B24 런은 서버 CUDA로 쟀다. 차이(+0.09)가 오차보다 훨씬 커서 결론에는 영향이 없다.

## 6. 공개 세트 확인 (B24_base 하나만, 선택·임계값에 쓰지 않음)

- examples_labeled 30장 (어려운 사례 모음): micro AP 0.799, macro AP 0.837, micro F1 0.725 (정밀도 0.71 / 재현율 0.74).
  오탐은 장갑 13·양말 8·안경 7·조끼/모자/머리장식/스카프 각 6, 누락은 탑 10·치마 10·재킷 7.
- test_public 30장 (라벨 없음, 눈으로만): 한 사람이 크게 찍힌 사진은 그럴듯하고 빈 장면은 잘 거른다.
  군중·작은 사람에서 모자와 장갑 오탐이 많고, 점수가 1.00 근처로 과신한다.

## 7. 다음 후보

- 작은 물체 recall과 군중 오탐 개선이 우선 (위치는 맞는데 점수가 낮거나, 작은 사람에서 소품을 과신).
- 그룹 softmax → 칸별 sigmoid 학습은 아직 미시험. 한 번 학습하면 추론 방식(sigmoid / 추론 때 softmax / 혼합)은 재학습 없이 비교 가능.
