# 현재 상황 재정리 (2026-11-14, 5번)

## 왜 다시 정리하나

기법을 계속 더해 왔지만, 각 기법을 **왜** 쓰는지, **얼마나** 효과가 있는지, **어떤 값이 맞는지**는 판단하지 않았다.
돌아보면 새 기법을 올리는 대신 이미 쓰고 있는 기법의 값을 바꾸거나 결과를 더 자세히 봤어야 하는 경우가 많았다.

이 문서는 다음 순서로 정리한다.
1. 지금 모델(R4)의 각 구성 요소
2. 효과가 없었거나 버린 기법
3. 실험 중인 4개
4. 다음에 할 일

수치 근거는 `기법효과_지도.md`에 있다. 그 문서의 기준을 그대로 쓴다: 임계값과 무관한 micro AP, 면적별 순위, holdout과 val 모두에서 유의할 때 ★.

## 1. R4 구성 요소: 왜 넣었고, 무엇을 아직 안 봤나

| 구성 요소 | 넣은 이유 | 확인된 효과 | 한 번도 바꿔 보지 않은 값 | 더 볼 것 |
|---|---|---|---|---|
| **고해상도 400~800 / 평가 800** | 작은 옷이 384에서 몇 픽셀만 남음 | ★ 가장 큼. 작은 옷일수록 효과가 큼 | 평가 해상도와 학습 상한을 함께 올리기. 960은 C1(증류 없음)에서만 시험했고 micro AP +0.003★ | R4 설정에서 960. 작은 옷 구간이 더 오르는지 |
| **증류 (FashionFormer R50)** | 0/1 정답보다 풍부한 목표를 줌 | ★ 해상도 다음으로 큼 (micro AP +0.015). 크기와 무관하게 고르게 개선 | **α 0.5, shift 0.3을 처음 값 그대로 썼다.** 교사 점수 온도, 교사 종류(Swin-B는 1회만) | α(0.3/0.7), shift. 가장 큰 효과를 내는 기법인데 조정한 적이 없다 |
| **stride 16 + 32 특징** | 더 세밀한 특징 지도 | GMP와 함께 바뀐 비교만 있음 (+0.003★) | stride 16만 빼 보기, stride 8 추가(코드 준비됨) | 각 단계의 단독 기여 |
| **GAP·GMP 0.5:0.5** | 최대는 작은 옷, 평균은 안정성 | 최대: 작은 옷 순위★. 평균: 보정만 | **0.5:0.5 비율** | 비율보다 임계값 보정 문제에 가깝다. 우선순위 낮음 |
| **BCE** | 4번 비교에서 ASL보다 약간 나음 | 고해상도 + 증류 조건에서 ASL과 차이 없음 | – | 끝난 질문 |
| **EMA 0.9995** | EVA 저해상도에서 유일하게 유의 | **고해상도에서는 확인한 적 없음** | decay 값 | R4에서 EMA 끄기 1회 |
| **AdamW, 백본/헤드 lr 분리, warmup, step decay, clip** | FashionFormer 설정을 가져옴 | FashionFormer lr로 바꿔도 차이 없음 | 감쇠 시점, epoch 수 | 우선순위 낮음 |
| **크기 증강 400~800** | 크기 변화에 강하게 | 순위 효과 없음 (보정만) | – | 끝난 질문 |
| **임계값: holdout macro F1로 하나 선택** | 규칙을 고정하려고 | **이 규칙 때문에 결론이 뒤집혔다.** 증류의 F1 효과는 고정 임계값에서 +0.007, 이 규칙에서 −0.006. 의사 라벨의 F1 하락도 이 규칙이 0.35를 골랐기 때문 | 선택 기준(micro, macro, 둘의 조합), 클래스별 임계값 | 기법 판단은 AP로 하고, 임계값은 마지막에 따로 정한다 |

**정리:** R4의 성능은 대부분 **해상도와 증류**에서 나온다. 그런데 증류는 처음 정한 값 그대로다. 새 기법을 더하는 것보다 증류 값을 조정하는 쪽의 기대 이득이 크다.

## 2. 효과가 없었거나 버린 기법: 무엇을 놓쳤나

| 기법 | 원래 목적 | 결과 | 놓친 것 / 값만 바꿨다면 |
|---|---|---|---|
| **모자이크 (2~9장, 50%)** | 군중 흉내 | 큰 옷 순위 하락★ | 타일이 작아져 큰 옷의 맥락이 사라진 것이 원인으로 보인다. **2장 이하, 낮은 확률(10~25%)**은 R4 설정에서 시험하지 않았다. 효과를 볼 군중 검증 세트도 없었다 |
| **CSRA + 마스크** | 옷 위치 학습, 혼동 감소 | 큰 옷 하락★. CSRA 헤드만 바꾸면 변화 없음 | 마스크 손실 가중치 0.5를 조정하지 않았다. 원인이 마스크 쪽이라는 걸 알기 전에 다음 기법으로 넘어갔다 |
| **COCO 의사 라벨** | 군중 분포 학습 | 순위 변화 없음. F1 하락은 임계값 선택 때문 | 같은 임계값에서는 거의 같았다. 군중에서 좋아졌는지는 **볼 데이터가 없어서** 판단할 수 없었다 |
| **gate + 빈 사진 + 사람 사진 + 증강 묶음** | 테스트 분포 대응 | 묶음 전체 손해★ (−0.016) | 여러 요소를 한꺼번에 넣어서 원인을 분리하지 못했다. 모자이크 단독 손해(−0.005)를 빼면 나머지 원인은 모른다 |
| **타일 추론** (학습 없음, 파라미터 증가 없음) | 군중에서 작은 사람 보기 | 군중 재현율 0.52 → 0.74 (예시, 진단). 하지만 사람 1명 사진에서 오탐이 급증 | **조건부 적용**(타일 예측에 더 높은 임계값, 사람이 많을 때만)을 끝까지 하지 않았다. 학습이 필요 없는 가장 직접적인 군중 대응인데 멈춘 상태다 |
| **외부 데이터 506 / 3,458 (384 해상도)** | 희귀 클래스 보강 | 효과 없음 | 384에서만 봤다. 지금 고해상도로 다시 확인 중이다 |
| **쿼리 헤드 C3 (ASL, 증류 없음)** | 혼동 감소 | 판단 불가 | 지금 R4 설정으로 다시 확인 중이다 |

**공통점:**
- 실패 원인을 확인하기 전에 다음 기법으로 넘어갔다.
- 효과를 확인할 데이터가 없는 목표(군중)에 기법을 계속 더했다. 군중 재현율은 테스트 예시 19장으로만 볼 수 있었고, 그건 선택에 쓸 수 없다. 그러니 군중용 기법은 처음부터 판정이 불가능한 구조였다.

## 3. 실험 중인 4개: 가설과 판정 기준 (결과를 보기 전에 정해 둠)

공통 기준:
- R4와 비교하고, 판정은 micro AP의 holdout과 val **둘 다** ★일 때만 한다.
- 다만 R4의 seed 잡음은 아직 재지 않았다. 지금까지 본 다른 설정의 seed 차이는 micro AP 0.0015 이내였다.

| 실험 | 가설 (왜 하는가) | 볼 것 | 이기면 | 지면 / 차이 없으면 |
|---|---|---|---|---|
| **R4 + 외부 3,458** (GPU 0) | 우산, 장갑, 조끼처럼 외부 양성이 많은 클래스는 데이터가 부족했다. 그래서 그 클래스만 좋아지고 나머지는 그대로일 것이다 | 전체 micro AP, **외부 양성이 많은 클래스의 AP**, 다른 클래스의 손해 여부 | 외부 데이터를 R4에 넣는다. 다음으로 외부 비율을 조정한다 | 외부 데이터 방향을 접는다. 이번에는 고해상도에서 확인했으니 근거가 분명해진다 |

### 3-1. 결과 (2026-11-15, holdout/val, TTA 800 + flip, 테스트 미사용)

**R4 seed 잡음.** R4 seed 43과 44를 같은 서버에서 다시 학습했다.

| 비교 | micro AP (holdout / val) | macro AP (holdout / val) |

| s43 → s44 (같은 서버) | +0.0001 / +0.0019 | +0.002 / +0.005 |

- 사용 허용 확인 (2026-11-15): FashionFormer 교사 모델(증류)과 Fashionpedia 분할 마스크는 써도 된다. DINOv3 라이선스는 아직 확인하지 않았다.
- 백본 교체가 해상도, 증류와 같은 수준의 효과를 냈다.

- 효과를 나눠 보면 이렇다.
  - ViT 구조는 **큰 옷**을 좋게 한다. DeiT-3와 DINOv3 ViT 모두에서 큰 옷 순위가 R4보다 +0.3~0.6 높다. 이미지 전체를 한 번에 보는 전역 어텐션과 맞는 결과다.

    2. R4 가중치는 384 해상도로 미세조정돼 있고, DINOv3 ConvNeXt에는 그 과정이 없다.
