| 항목 | EVA02-S 기준선 | **EVA02-S V2 (외부 3,458장 추가)** | 차이 |
|---|---|---|---|
| 입력 / 손실 / 임계값 | 378 / BCE / 0.5 | 378 / Masked BCE / 0.5 | |
| holdout macro | 0.708 | 0.699 | −0.009 |
| val micro / macro / image | 0.811 / 0.632 / 0.816 | 0.809 / 0.595 / 0.814 | −0.002 / **−0.037** / −0.002 |
| 클래스 (val) | | 8개 상승, 19개 하락 | |
| macro 하락 중 작은 4개 클래스(val 양성 3~7장) 몫 | | −0.0295 / −0.0371 = **79.6%** | |
| holdout BCE | | ep2 최저 0.151 → ep19 0.310 | 빨리 외움 |

**우리 이야기에 주는 의미 세 가지**
1. **"384 근처 해상도에서 외부 데이터를 넣어도 안 오른다"는 세 번째 확인이다.** 1차 506장(EVA), 2번 3,458장(ConvNeXt, macro −0.009), 3번 3,458장(EVA, macro −0.037)이 모두 같은 방향이다. 데이터 양이 아니라 입력 해상도가 병목이라는 우리 진단과 맞는다.
2. **같은 "빨리 외우는" 곡선이 다시 나왔다.** holdout BCE가 2 epoch 이후 계속 오른다. 384 ConvNeXt 13개 실험에서 본 현상과 같고, 고해상도 C1에서는 holdout BCE가 17 epoch까지 내려갔다.
3. **macro 하락의 대부분은 양성 3~7장 클래스에서 나온다.** 우리 최고 조합의 macro 하락(2절)을 설명할 때 같은 분해를 쓰면 된다.
4. (참고) **"AI에게 맡기면 0.8"의 기준점**으로 쓸 수 있다. EVA V2의 val micro 0.809가 그 수준이고, 같은 val에서 C1은 0.868, 최고 조합은 0.883이다. 단, 해상도·TTA·임계값 선택이 달라 **조건이 같은 비교는 아니다.** 발표에서는 "참고선"으로만 쓴다.

## 지적 1. "실험 수에 비해 결론이 적다"

**한 줄 답:** 갈래마다 가설과 판정을 미리 적었고, 기각된 실험이 다음 실험을 정했다. 효과가 확인된 것은 해상도, EMA, 증류, stride 16 + 최대 풀링 네 가지다.

**발표용 실험 지도** (val, 같은 표 안에서만 비교)

| 가설 | 실험 | 판정 | 다음으로 이어진 것 |
|---|---|---|---|
| optimizer·정규화가 병목 | 384 ConvNeXt 13개 (Muon, LP-FT, layer decay, EMA, drop path) | ❌ 차이 0.01 안쪽, 모두 2~3ep 뒤 holdout BCE 상승 | "빨리 외우는" 원인을 입력에서 찾음 |
| 외부 데이터가 병목 | 506 (EVA, ConvNeXt), 3,458 (ConvNeXt, EVA V2) | ❌ macro −0.009 ~ −0.037 | 데이터 문제 아님 |
| **해상도가 병목** | FashionFormer 측정 → 800/1333 ConvNeXt | ✅ macro 0.661 → 0.744, holdout BCE 계속 하락 | 고해상도를 기본으로 |
| 해상도를 더 올리면 더 좋다 | 480~960 | ❌ 모두 구간이 0을 포함 | 800에서 포화 |
| 큰 모델의 지식을 옮긴다 | 증류 | ✅ micro +0.007 | |
| 작은 물체엔 고해상도 특징 + 최대값 | 증류 + GAP·GMP | ✅ micro +0.016 (C1 대비) | |
| 클래스별 attention이 혼동을 줄인다 | 쿼리 헤드 C3, CSRA | 🟡 혼동 149 → 123, micro는 −0.007 | 최종 조합 후보 B |
| 테스트 분포(OOD) 대응 | gate v1 → v2, 증강 ①② | 🟡 빈 사진 97.5% 처리, 군중 재현율 0.47 | crop 진단 |
| **군중 실패는 스케일 때문** | 사람 crop 추론 (진단) | ✅ 재현율 0.54 → 0.77 | 타일 추론 |

**발표에서 이렇게 줄인다**
- 본문: 해상도 → 증류·헤드 → OOD 진단(crop) → 해결(타일). 슬라이드 4~5장.
- 나머지(Muon, LP-FT, layer decay, 480~960, C3, gate v1, 증강 ①②)는 **부록 표 한 장**으로 "시도했지만 효과 없음"과 판정 근거만 둔다.

## 지적 2. "최고 조합은 macro가 떨어졌다" (0.746 → 0.733)

**한 줄 답:** macro 차이는 유의하지 않다(−0.012, 구간이 0 포함). 하락은 거의 cape 하나(val 양성 5장 중 4장 → 0장)에서 나왔다. 양성 7장 이하 4개 클래스를 빼면 macro는 오히려 **+0.026** 올랐다.

**결과** (C1 → 증류 + GAP·GMP, 둘 다 임계값 0.60, 반전 TTA, 쌍 부트스트랩 2,000회)

| 항목 | val | holdout |
|---|---|---|
| micro 차이 [95% 구간] | **+0.016 [+0.009, +0.023]** | **+0.014 [+0.009, +0.019]** |
| image 차이 | **+0.014 [+0.007, +0.022]** | **+0.011 [+0.005, +0.016]** |
| macro 차이 | −0.012 [−0.041, +0.016] (유의 X) | −0.007 [−0.025, +0.010] (유의 X) |
| 양성 ≤7 클래스(cape, tie, leg warmer, umbrella)의 몫 | **−0.034** | (holdout엔 해당 없음) |
| 그 4개를 뺀 macro | 0.759 → **0.785 (+0.026)** | 0.791 → 0.784 (−0.007) |
| 오른 / 내린 클래스 | 22 / 4 (1개 동률) | 21 / 4 (2개 동률) |

**떨어진 클래스는 두 분할에서 같다: 희귀 클래스**

| 클래스 | val 양성 | val TP (C1 → 최고 조합) | holdout 양성 | holdout TP |
|---|---|---|---|---|
| cape | 5 | 4 → 0 (F1 0.89 → 0) | 16 | 6 → 3 |
| umbrella | 5 | 5 → 4 | 20 | 17 → 14 |
| leg warmer | 7 | 0 → 1 (오름) | 8 | 4 → 2 |

- 나머지 클래스 대부분은 **FP가 줄면서** 올랐다 (val top FP 93 → 70, bag 30 → 17, vest 11 → 2, jumpsuit 13 → 5). 비슷한 옷을 덜 헷갈린다는 혼동 지표(149 → 132)와 같은 방향이다.

**발표 문장:** "micro·image는 유의하게 올랐다. macro −0.012는 유의하지 않고, 그 대부분이 val 양성 5장인 cape 한 클래스에서 나왔다. 희귀 클래스 4개를 빼면 macro는 +0.026이다."

**정직하게 말할 것:** holdout에서도 cape·umbrella·leg warmer가 함께 떨어졌다. 한 분할의 우연만은 아니다. **새 모델은 희귀 클래스에 더 보수적이다**(TP와 FP가 함께 줄었다). 증류 교사(FashionFormer)의 희귀 클래스 점수가 낮았거나, 최대 풀링이 작은 클래스를 덜 밀어 주는 것일 수 있다. 원인은 아직 확인하지 않았다. 대응 후보: 희귀 클래스만 임계값을 낮추기(holdout으로 고름), copy-paste 증강.

```bash
python experiments/role5_regularization/defense_stats.py macro R5_cnxt_hr_s42:0.60 R5_cnxt_hr_kd_msmax_s42:0.60 --out /data/eunjin/DL/logs/defense_macro.json
```

## 지적 3. "seed가 하나인 결과가 많다"

**한 줄 답:** 큰 결론(해상도, +0.04~0.08)은 seed 흔들림보다 훨씬 크다. 작은 차이(+0.007~0.016)는 최종 조합에서 seed 2개로 직접 잰다.

**지금 있는 근거**
- 해상도 효과: C1 − 384 기준선 val micro +0.038, macro +0.067 [+0.036, +0.105]. 부트스트랩 구간 하한도 0.03을 넘는다.
- 쌍 부트스트랩은 **이미지 표본의 흔들림**만 잡는다. **학습 seed의 흔들림은 잡지 못한다.** 이 한계를 먼저 말한다.

**채울 값 ⏳** (최종 조합 4개가 끝나면)

| | val micro | val macro | val image |
|---|---|---|---|
| seed 차이: GAP·GMP s43 − s42 | ⏳ | ⏳ | ⏳ |
| seed 차이: CSRA s43 − s42 | ⏳ | ⏳ | ⏳ |
| 헤드 차이: CSRA 평균 − GAP·GMP 평균 | ⏳ | ⏳ | ⏳ |

- 헤드 차이가 seed 차이보다 작으면 "두 헤드는 구별되지 않는다"로 보고하고, 혼동·OOD 지표로 고른다.
- 계획서 STEP 9의 seed 3개는 이긴 헤드에 1개를 더 돌려 채운다.

```bash
python experiments/role5_regularization/defense_stats.py seeds R5_final_msmax_s42:0.60 R5_final_msmax_s43:0.60 R5_final_csra_s42:0.50 R5_final_csra_s43:0.50 --out /data/eunjin/DL/logs/defense_seeds.json
```
(임계값은 각 실행에서 holdout으로 고른 값으로 바꿔 넣는다.)

## 지적 4. "추론이 무겁다 / 검출기는 50M에 포함되나"

**한 줄 답:** 제출 모델은 27.85M(50M의 56%) 하나다. 반전 TTA와 타일 추론은 파라미터를 늘리지 않는다. 사람 검출기 crop은 원인을 확인하는 진단에만 썼고 제출에는 넣지 않는다.

| 추론 방식 | 파라미터 | 이미지당 forward 수 | 시간 (A5000) | 용도 |
|---|---|---|---|---|
| 단일 | 27.85M | 1 | 10.4 ms (측정) | |
| 반전 TTA | 27.85M | 2 | 약 20 ms (측정) | 제출 기본 |
| 타일 full + 3×3 | 27.85M | 10 × 2 = 20 | 약 200 ms (추정, 타일도 짧은 변 800으로 키움) | **지금 형태로는 채택 불가** (아래) |
| 사람 검출 crop | 27.85M + Faster R-CNN v2 43.7M = **71.5M** | 1 + 사람 수 | – | **진단 전용, 50M 초과로 제출 불가** |

- 타일을 쓰게 되면 제출 환경의 시간 제한을 조교에게 확인해야 한다 (중간점검 10장 3번).
**타일 추론 결과** (C1, 임계값 0.60, 클래스별 최대값, `scripts/tile_infer.py`)

| 추론 | 예시 30장 micro / 재현율 / 정밀도 | 예시 라벨 수 오차 | 테스트 300장 이미지당 예측 | val micro / macro / image | val 이미지당 예측 |
|---|---|---|---|---|---|
| full | 0.640 / 0.524 / 0.820 | 3.63 | 4.66 | **0.869 / 0.748 / 0.869** | 3.37 |
| full + 2×2 | 0.671 / 0.610 / 0.746 | 2.83 | 6.41 | 0.822 / 0.692 / 0.830 | 4.02 |
| full + 3×3 | **0.684 / 0.744** / 0.633 | **2.70** | 9.85 | 0.576 / 0.450 / 0.574 | 7.53 |
| full + 2×2 + 3×3 | 0.678 / 0.744 / 0.623 | 2.80 | 10.05 | 0.574 / 0.447 / 0.572 | 7.61 |

- 군중 사진에서는 타일이 효과가 있다. 재현율 0.52 → 0.74로, crop 진단(0.77)과 거의 같다. 검출기 없이 스케일 문제를 풀 수 있다는 뜻이다.
- **단일 인물 사진(val)에서는 크게 망가진다** (micro 0.869 → 0.576). 사람 한 명을 조각내면 조각마다 "있을 법한" 옷을 최대값으로 더해서 FP가 폭증한다.
- 결론: **타일을 모든 사진에 일괄로 적용하면 안 된다.** 다음 후보는 세 가지다.
  1. 군중일 때만 타일을 적용한다. 사람 수 판단에 검출기를 쓰면 50M을 넘으므로, 모델 자체의 신호(예: 라벨 수나 gate)로 판단해야 한다.
  2. 타일 쪽 점수에 더 높은 임계값을 쓰거나, 타일 2개 이상이 동의해야 채택한다.
  3. 학습 단계에서 군중 사진을 보여 준다 (모자이크와 큰 데이터 실험).
- val과 예시 둘 중 하나라도 유의하게 나빠지면 탈락한다는 선택 기준(중간점검 10장 4번)에 따라, 타일은 지금 형태로는 탈락이다.

## 지적 5. "더 큰 모델(FashionFormer)에 기댄 것 아니냐"

**한 줄 답:** FashionFormer는 학습할 때 정답 옆에 붙이는 점수로만 쓴다. 추론에는 들어가지 않는다. Fashionpedia로 학습된 모델 사용은 교수님이 허용했다.

- 효과는 따로 떼어 냈다
  - 증류 − C1: val micro +0.007 (유의)
  - 증류 + GAP·GMP − 증류: +0.009 (유의, 헤드 효과)
- 빠진 대조: **증류 없는 GAP·GMP 단독은 돌리지 않았다.** 질문이 나오면 그대로 인정하고, 위의 두 단계 차이로 각각의 효과를 설명한다.
- 증류 없이도 C1이 FashionFormer(44.1M)를 이겼다: val macro +0.039 [+0.010, +0.072]. 교사보다 학생이 이미 앞서 있었다는 점이 "기댄 것"이 아니라는 근거다.
- 주의: FashionFormer는 train2020으로 학습해서 holdout 점수는 부풀려진다. 그래서 비교는 val로만 했다.

## 지적 6. "val에 맞춰 고른 것 아니냐"

**한 줄 답:** epoch과 임계값은 holdout으로만 골랐고, val은 보고에만 썼다.

- 예외 하나: sweater·leg warmer·umbrella의 임계값 0.5는 holdout 클래스 표를 보고 정했다. 이 이득(+0.006)은 낙관적이라고 문서에 이미 적었다.
- 테스트 예시 30장은 경향을 볼 때만 쓰고, 임계값이나 모델 선택에는 쓰지 않았다.

## 지적 7. "val 0.88인데 실제 사진에서는 0.65다"

**한 줄 답:** 테스트 분포가 다르다는 걸 발견하고 원인을 쟀다. 임계값 문제가 아니라 스케일 문제였다.

- 테스트 300장 중 50%가 군중 사진이다. train은 대부분 1명이다.
- 놓친 라벨의 62%는 확률이 0.2 미만이다. 임계값을 낮춰도 못 살린다.
- 사람을 잘라 크게 보여 주면 재현율이 0.54 → 0.77, 군중 사진은 0.47 → 0.75로 오른다. 백본은 옷을 알아본다. 사진 속 사람이 작아서 못 본 것이다.
- 해결 시도: 검출기 없이 타일로 나눠 보는 추론. 예시 재현율은 0.52 → 0.74로 올랐지만, val 단일 인물 사진에서 오탐이 폭증했다 (지적 4). **"원인은 찾았고, 일괄 적용은 실패했으며, 조건부 적용을 시험 중"**이 지금 상태다.
- **현직자에게 물을 질문:** "남은 시간에 val을 0.01 더 올리는 것과 실제 분포 대응 중 어디에 투자하나요?"
