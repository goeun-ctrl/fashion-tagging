# 중간발표 피드백 반영

교수님 피드백은 "여러 기법을 썼는데, 각 기법이 실제로 어떻게 작동하고 왜 성능에 영향을 줬는지 설명이 부족하다"는 것이었다.
이 문서는 두 가지를 정리한다.

1. 발표 때 답하지 못한 사실 질문: 코드로 확인한 답.
2. 실험별 해석: 목적 → 바꾼 변수 → 결과 → 원인 해석.

- 근거 코드: `scripts/train_hires.py`, `scripts/pseudo_label.py`, `src/fashion_tagging/training/losses.py`
- 근거 설정: 서버 `runs_hr/<실험>/config.json`
- 테스트 예시 30장은 진단에만 썼고, 이 문서의 어떤 비교나 선택에도 쓰지 않았다.

## 1. 입력 해상도: Resize인가, Crop인가 (코드 확인 완료)

**결론: Crop은 쓰지 않는다. 가로세로 비율을 유지한 Resize와 오른쪽·아래쪽 패딩만 쓴다.**

| 단계 | 실제 동작 | 코드 위치 |
|---|---|---|
| 백본 | `convnext_tiny.fb_in22k_ft_in1k_384`: ImageNet-22k로 사전학습하고 ImageNet-1k의 **384×384**로 미세조정된 가중치 | config `model` |
| 학습 크기 | 이미지마다 짧은 변을 {416, 544, 672, 800} 중 하나로 무작위로 고른다(400~800을 4단계로 나눔, 32의 배수). 긴 변은 min(1333, 2×짧은 변) 이하로 제한한다. | `short_levels`, `target_size`, `long_cap` |
| Resize | `target_size`: scale = min(짧은 변 목표/짧은 변, 긴 변 상한/긴 변). 비율을 유지한 bilinear Resize이고, mmdet의 `Resize(keep_ratio=True)`와 같다. | `HiResDataset.__getitem__` |
| Crop | **없다.** 코드 주석에도 "crop을 하면 잘린 물체의 라벨이 여전히 1로 남는다"고 적혀 있다. | 파일 맨 위 docstring |
| 좌우 반전 | 확률 0.5 | `--flip 0.5` |
| 배치 구성 | 같은 방향(세로·가로)과 같은 크기 단계의 이미지끼리 묶는다. 각 이미지를 그 단계의 고정 캔버스(32의 배수)에 왼쪽 위로 붙이고, 남는 곳은 0으로 채운다. | `pad_collate` |
| 패딩 처리 | 특징 지도에서 실제 이미지 영역만 풀링한다. 평균은 패딩 칸을 0으로 두고 실제 칸 수로 나누고, 최대는 패딩 칸을 최솟값으로 둔다. 그래서 패딩은 예측에 들어가지 않는다. | `valid_mask`, `masked_pool` |
| 평가 크기 | 짧은 변 800, 긴 변 1333 이하로 하나만 쓴다. 반전 TTA를 하면 원본과 반전 예측을 평균한다. | `test_short 800` |

**224 입력 질문에 대한 답**
- ConvNeXt의 stem은 4×4, stride 4 합성곱이고, 이후 단계도 모두 합성곱과 다운샘플링이다. 위치 임베딩처럼 입력 크기에 묶인 부분이 없다.
- 그래서 입력 층을 바꾸지 않고 800×1333 입력을 그대로 넣을 수 있다. 출력은 stride 16과 32 특징 지도이고, 크기만 커진다.
- 크기가 달라도 마지막에 공간 풀링을 하므로 분류 헤드의 입력 차원(1,152)은 같다.
- 우리 가중치는 224가 아니라 384로 미세조정된 버전이다.

**발표용 답변 (30초)**
> 원본을 자르지 않고, 가로세로 비율을 유지한 채 짧은 변이 400~800이 되도록 Resize합니다. 멀티라벨이라서 Crop을 하면 잘린 옷의 라벨이 남는 문제가 생기기 때문에 일부러 쓰지 않았습니다. 배치를 만들 때 생기는 패딩은 풀링에서 제외합니다. ConvNeXt는 합성곱 구조라 입력 크기에 제한이 없어서 백본을 바꾸지 않았고, 평가는 짧은 변 800으로 합니다.

## 2. 실험별 X · Y · 손실 (코드 확인 완료)

표기는 다음과 같다.
- **FP**: Fashionpedia 학습 이미지(train_inner, 43,197장)
- **y**: 27개 정답 라벨
- **p_T**: 교사 점수
- **-1**: 미확인 라벨. 손실 평균에서 빼고, 알려진 칸으로만 평균한다(`_masked_mean`).

| 실험 | 입력 X | 정답 Y | 손실 | 교사 |
|---|---|---|---|---|
| **R4 (증류)** | FP만 | y(0/1) + p_T(27개 점수) | 0.5·BCE(학생, y) + 0.5·BCE(학생, p_T) | FashionFormer R50. 학습 이미지 점수를 미리 계산해 저장. 로짓을 이동해 교사의 0.3이 0.5가 되게 함 |
| **COCO 의사 라벨** | FP + COCO 군중 19,000장(epoch당 10,799장, 전체의 20%) | FP: y + p_T. COCO: 의사 라벨 1 / 0 / -1 | FP 쪽은 R4와 같다. COCO는 BCE(학생, 의사 라벨)이고 -1 칸은 뺀다. **COCO에는 증류 항이 없다**(교사 점수가 없음). | 우리 학생 모델(R5_cnxt_hr_kd_msmax). 전체 이미지와 COCO 사람 박스 최대 6개(높이 64px 이상)를 크롭해 반전 TTA로 점수를 낸 뒤 클래스별 최댓값을 쓴다. |
| **gate (최종 조합)** | FP + 사람 없는 사진 8,003장(COCO 4,706 + Places 3,297) + 사람 있는 사진 7,444장(COCO 4,500 + Places 2,944). 각각 epoch의 10%. | 27개 클래스 + gate 1칸. 사람 없음: 27개 모두 0, gate 0. 사람 있음: 27개 -1, gate 1. FP: y, gate 1. | (1−0.5)·[ASL(27개) + 1.0·BCE(gate)] + 0.5·BCE(학생, p_T). 증류는 FP에만 적용. | FashionFormer R50 (증류) |
| **CSRA + 마스크** | FP | y + p_T + 클래스별 마스크(stride 16, FP 분할 주석) | R4 손실 + 0.5·마스크 손실(CSRA 점수 지도의 칸별 BCE) | FashionFormer R50 |
| **모자이크** | FP. 50% 확률로 2, 4, 6, 9장을 이어 붙인 사진 | 붙인 사진들 라벨의 합집합. p_T는 칸별 최댓값. | R4와 같음 | FashionFormer R50 |

- **의사 라벨 기준:** 확률 0.8 이상이면 1, 0.2 이하면 0, 그 사이는 -1이다.
  - 기준은 holdout에서 정했다. 0.8 이상의 정밀도는 0.924, 0.2 이하의 음성 예측도는 0.997이다.
  - COCO 사진 한 장당 양성은 평균 2.54개다. 칸 기준으로 양성 9.4%, 음성 43.5%, 미확인 47.1%다.
- **증류와 의사 라벨의 차이**
  - 증류는 정답이 있는 같은 이미지에 교사의 연속 점수를 더하는 방법이다. 의사 라벨은 정답이 없는 새 분포의 이미지에 0/1 라벨을 만들어 넣는 방법이다.
  - 교사도 다르다. 증류는 FashionFormer를 썼고, 의사 라벨은 우리 ConvNeXt 모델을 크롭 방식으로 썼다.
  - 위험도 다르다. 증류의 위험은 교사의 오류가 그대로 옮겨오는 것이다. 의사 라벨의 위험은 라벨 오류와 도메인 차이가 같이 들어오는 것이다.

**발표 때 섞여서 설명된 부분:** R4에는 COCO 이미지가 하나도 들어가지 않는다. COCO는 두 실험에서만 쓰였다. 의사 라벨 실험은 27개 라벨을 만들어 썼고, gate 실험은 사람이 있는지만 라벨로 썼다.

## 3. 실험 해석: 임계값과 무관한 지표를 추가

지금까지는 F1만 보고 판단했다. 그런데 F1은 **임계값을 어디에 두느냐**에 따라 달라진다. 그래서 차이가 생겼을 때, 모델이 옷을 더 잘 보게 된 건지(순위 품질), 확률을 다르게 내게 됐을 뿐인지(보정)를 구분할 수 없었다.

이를 구분하려고 임계값 없이 계산하는 **AP(Average Precision)**를 추가했다.
- macro AP: 클래스별 AP의 평균
- micro AP: 모든 칸을 합쳐서 계산한 AP
- 구간은 F1과 같은 방식으로 냈다. 이미지 단위 쌍 부트스트랩 2,000회, 95% 구간이다.
- 원본 로그: 서버 `logs/ap_cmp.txt`

### 3-1. R4 대비 변형 (holdout. 굵은 글씨는 0을 포함하지 않는 구간)

| 변형 | 바꾼 것 | F1 micro 차이 | F1 macro 차이 | **micro AP 차이** | macro AP 차이 | 해석 |
|---|---|---|---|---|---|---|
| GAP만 | 풀링 | −0.002 [−0.006, +0.001] | +0.004 | **−0.003 [−0.005, −0.002]** (val도 −0.004) | −0.003 | 최대 풀링을 빼면 순위 품질이 조금 떨어진다. 최대 풀링이 실제로 정보를 더한다. |
| GMP만 | 풀링 | **−0.007** | −0.003 | 0.000 [−0.001, +0.001] | +0.005 | 순위 품질은 같다. F1 하락은 확률 분포가 달라진 결과(오탐 증가, 임계값 0.35)다. |
| 짧은 변 800 고정 | 크기 증강 | **−0.004** | −0.010 | 0.000 [−0.001, +0.002] | +0.001 | 순위 품질은 같다. 크기 증강의 효과는 보정 쪽이고, 옷을 보는 능력 자체에는 차이가 없다. |
| 의사 라벨 | 데이터(COCO 군중) | **−0.011** | −0.007 | +0.001 [−0.001, +0.002] | −0.005 | 순위 품질은 같고, 예측을 더 많이 내서 F1이 떨어진다. 앞서 분석한 "예측 수 증가"와 일치한다. |
| CSRA + 마스크 | 헤드 + 마스크 지도 | −0.004 | **−0.013** | **−0.005 [−0.007, −0.003]** (val도 −0.004) | −0.011 | 실제로 순위 품질이 나빠졌다. 헤드만 바꾼 비교에서는 차이가 없었으므로, 원인은 마스크 지도 쪽일 가능성이 크다(해석). |
| 모자이크 | 증강 | −0.005 | **−0.021** | **−0.005 [−0.006, −0.003]** (val도 −0.004) | −0.009 | 실제로 순위 품질이 나빠졌다. 붙인 사진은 작고 경계가 부자연스러워서 실제 분포와 다른 것으로 해석한다. |
| Swin-B 교사 | 교사 | 0.000 | +0.006 | 0.000 | **+0.012 [+0.001, +0.025]** (val은 +0.004, 구분 안 됨) | 강한 교사가 희귀 클래스 쪽 순위를 개선했을 가능성이 있다. val에서 재현되지 않아 확정하지 않는다. |

### 3-2. 증류 자체의 효과 (ASL 설정에서 증류만 켜고 끈 쌍: C1 대 KD)

| 지표 | 임계값 0.6 / 0.55 고정 | holdout에서 각자 고른 임계값 (0.7 / 0.5) | 임계값 없음 (AP) |
|---|---|---|---|
| holdout micro | **+0.007 [+0.002, +0.011]** | **−0.006 [−0.010, −0.001]** | micro AP **+0.015 [+0.012, +0.018]** |
| val micro | **+0.007 [+0.001, +0.014]** | **−0.009 [−0.016, −0.002]** | micro AP **+0.012 [+0.007, +0.016]** |
| macro | 구분 안 됨 | 구분 안 됨 | macro AP 구분 안 됨 |

- **해석:** 증류는 순위 품질(micro AP)을 holdout과 val 양쪽에서 확실히 올린다. 즉 흔한 클래스를 "옷이 있는 사진에 더 높은 점수를 주도록" 만든다.
- 하지만 F1은 임계값을 어떻게 고르느냐에 따라 부호가 뒤집힌다. 임계값을 macro 기준으로 고르면 KD는 0.5, C1은 0.7이 선택된다. 이때는 micro가 오히려 떨어진다.
- 그래서 "증류가 F1을 올렸다"보다 **"증류는 순위 품질을 올렸고, 희귀 클래스(macro)에는 효과가 확인되지 않았다"**가 정확한 표현이다.
- 발표에서 말한 "증류 후 val micro +0.007"은 임계값을 고정한 조건의 값이다. 이 조건을 함께 밝혀야 한다.

### 3-3. 고해상도 입력

- 같은 설정에서 입력만 높였을 때 val macro +0.033 [+0.005, +0.065]이었다(발표 슬라이드 6).
- 800 고정 실험을 보면 holdout BCE는 끝까지 평평했다(0.108). 그래서 조기 과적합이 사라진 것은 크기 증강보다 해상도 쪽의 효과로 본다.
- "작은 물체에 대한 효과"는 아직 검증하지 않았다. 클래스 크기별 분석이 필요하다(4번 계획 C).

|---|---|---|

| 증류 | micro AP +0.015 (holdout), +0.012 (val) | 순위 품질 개선 확인. F1은 임계값에 따라 달라짐. 희귀 클래스 효과는 미확인 |

GPU 4개를 쓰면 A, D, E는 동시에 하루 안에 끝난다. B와 C는 학습 없이 바로 할 수 있다.

## 5. "왜 그런가": 작동 원리 확인 (2026-11-14, 학습 없음, holdout과 val만 사용)

**방법**
- 각 양성(이미지 × 클래스)마다 **순위 점수**를 계산했다. 같은 클래스의 음성 사진 중 몇 %보다 점수가 높은지를 나타내는 값으로, 임계값과 무관하다.
- 옷 면적은 Fashionpedia 주석에서 가져왔다. 가장 큰 인스턴스의 면적을 이미지 면적으로 나눈 값이다.
- 면적 구간: 0.5% 미만(holdout 2,764개: shoe, glasses, belt, watch, headband 위주), 0.5~2%, 2~8%, 8% 이상(holdout 1,835개: dress, jacket, top, pants, coat 위주)

### 5-2. 증류가 바꾼 것

- **비슷한 옷을 구분하는 효과보다 전반적인 효과가 더 크다.**
  - 같은 옷 그룹(상의 7개, 하의·원피스 5개, 레그웨어 3개)의 다른 옷이 있는 "어려운 음성"을 기준으로 보면 +0.86 [+0.65, +1.08]이다(val +0.71).
  - 그런 옷이 없는 "쉬운 음성"을 기준으로 보면 +1.40 [+1.18, +1.64]이다(val +1.32).
- **교사는 비슷한 옷에 실제로 중간 점수를 준다.** 학습 데이터에서 상의 그룹의 어려운 음성 평균은 0.128이고, 쉬운 음성은 0.051이다. 그래서 "교사가 비슷함을 알려준다"는 정보는 들어가 있다. 하지만 학생의 이득은 그보다 넓게 나타났다.
- **클래스 빈도와 관계없다.** 학습 빈도와 AP 변화의 순위 상관은 holdout −0.16, val 0.05다. 흔한 9개 클래스는 두 데이터 모두 개선됐다(+0.014 / +0.009). 희귀 클래스는 양성이 3~7개라 cape, umbrella, leg warmer에서 크게 흔들려 판단할 수 없다.
- **해석:** 증류는 특정 옷이나 혼동 쌍을 고치는 게 아니라, 0/1 라벨보다 부드러운 목표로 순위 전반을 안정시킨다.
  - 교사가 라벨 0인데 0.5 넘게 준 경우가 1.7%, 라벨 1인데 0.5 미만으로 준 경우가 7.2%다.
  - 주석 누락을 완화한다는 가설과 맞지만, 이건 아직 사진으로 확인하지 않았다.

### 5-3. 의사 라벨이 F1을 떨어뜨린 이유

- 임계값을 R4와 같은 0.4로 맞추면 예측 수는 holdout 9,409 → 9,459(+0.5%), val 4,011 → 4,007로 거의 같다.
- 따라서 발표에서 말한 holdout micro −0.011은 대부분 **임계값 선택 결과(0.35)** 때문이다. 모델 자체의 차이는 작다.
- 같은 임계값에서 bag과 scarf는 오탐이 조금 늘었다. 순위 품질이 오른 곳은 중간 크기 옷(상의, 하의)뿐이다.

### 5-4. 정성 근거 (holdout, `fashion_tagging/why_review/`, 저장소 밖)
