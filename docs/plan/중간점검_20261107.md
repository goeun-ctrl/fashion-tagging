## 0. 한 페이지 요약

1. **입력 해상도가 병목이었다.**
   - 384 정사각형에서 비율을 유지한 800/1333 입력으로 바꾸자, 같은 ConvNeXt-T(27.8M)의 val macro가 0.661에서 0.744로 올랐다.
   - 이 모델은 Fashionpedia 공개 체크포인트인 FashionFormer(44.1M, val 0.858 / 0.705 / 0.861)도 넘었다.
2. **그 뒤의 개선은 작고, 일부만 유의하다.**
   - 증류(FashionFormer 점수)와 stride 16·32 GAP·GMP 헤드를 합친 모델이 val micro 0.883으로 지금까지 가장 높다.
   - 반면 macro는 어떤 실험에서도 유의하게 오르지 않았다. 양성이 5~7장뿐인 클래스가 크게 흔들리기 때문이다.
3. **새 핵심 문제는 테스트 분포(OOD)다.**
   - 제공된 테스트 데이터는 Fashionpedia와 많이 다르다. 300장 중 50%가 군중 사진이고, 흑백 13%, 사람 없는 사진 6%, 이미지당 정답 라벨은 약 9개다.
   - 라벨이 있는 예시 30장에서 우리 모델의 micro는 0.63~0.66로, val(0.87~0.88)보다 0.2 이상 낮다.
   - 놓친 라벨의 62%는 확률이 0.2 미만이다. 임계값 문제가 아니라 **인식 문제**다.
4. **OOD 대응으로 효과를 확인한 것**
   - 빈 사진 + 사람 사진 + gate 출력: 빈 사진은 97.5%를 비우고, 사람 사진 오탐은 12%다.
   - zoom-out·모자이크 증강: 군중 재현율 0.43 → 0.47
   - 옛날 사진 증강: 사람이 있는데 비워 버리는 경우를 줄였다.
5. **지금 진행 중:** 위 요소를 모두 합친 최종 조합을 처음부터 학습하고 있다. 헤드 2종 × seed 2개, GPU 4장, 11/7 저녁 종료 예정이다.
6. **바로 다음 단계:** 원본 마스크로 클래스별 점수 지도를 학습하는 실험. 코드와 데이터는 준비됐고 학습만 남았다.
7. **빠진 단계:** 제출 파이프라인(오프라인 `predict.py`, ZIP, requirements), 최종 후보 seed 3개, 가중치 공유와 코드 병합, 조교 확인 2건. 자세한 내용은 9장에 있다.

**2번 정은의 27개 카테고리 상세 비교** (`feature/convnext-common3458-results`, `27개카테고리_상세비교보고서.md`)
- 외부 3458은 원본-only보다 val micro +0.007, image +0.004 높다. 반면 **macro는 −0.009**다.
- val 기준으로 16개 클래스가 올랐고 10개가 떨어졌다.
- 떨어진 쪽의 기여가 큰 클래스: leg warmer −0.25, glove −0.21, cardigan −0.14, umbrella −0.14, watch −0.13
- 오른 클래스: cape +0.33, tie +0.14, hat +0.06, sock +0.06, skirt +0.04
- 보고서 결론은 "외부 데이터의 일관된 효과는 확인되지 않음"이다. 단일 seed이고, 부분 라벨·도메인·샘플링 효과를 분리하지 못했다.
- 5번 해석
  - 1차 증강(외부 1.9%, 색 변화 13%)과 마찬가지로, 384 입력에서는 데이터를 늘려도 이득이 작다.
  - 작은 클래스(양성 5~21장)의 변화는 부트스트랩 구간 안이라 판단할 수 없다.
  - **외부 3458은 아직 고해상도 파이프라인에서 시험하지 않았다.** 9장 B5에 후보로 남긴다.

| 모델 | 사람 사진 1,000장 오탐 (잘못 비움) | 빈 사진 1,000장 정답률 (비움) |
|---|---|---|
| gate v1 | **40.8%** | 100% |
| gate v2 | 12.3% | 97.5% |

## 4. 지금까지 알게 된 것

1. **해상도가 가장 큰 요인이었다.** 384 정사각형에서 800/1333으로 바꾼 효과가 다른 모든 개선을 합친 것보다 크다.
   - 800 위로 올리면 효과가 없다 (480~960 실험).
2. **EMA, 증류, stride 16 + 최대 풀링은 유의한 효과가 있었다.**
   - 반면 optimizer 종류(Muon), layer decay, LP-FT, 1차 외부 데이터(506), FashionFormer lr, 넓은 크기 증강은 효과가 없거나 손해였다.
3. **쿼리 헤드(C3)는 파라미터만 2.2M 늘고, 목표였던 혼동은 줄이지 못했다.** 혼동을 줄인 건 증류(149→142)와 CSRA(→123)였다.
4. **val과 테스트 분포가 다르다.**
   - val에서 가장 좋은 모델(증류 + GAP·GMP)이 테스트 예시의 군중 사진에서는 가장 나쁘다 (재현율 0.37).
   - **val만으로 최종 모델을 고르면 안 된다.**
5. **빈 사진만 넣으면 지름길 학습이 생긴다** (gate v1).
   - 모델이 "사람이 있나"가 아니라 "Fashionpedia처럼 생겼나"를 배웠고, 사람 사진의 41%를 비웠다.
   - 같은 스타일의 사람 사진을 양성으로 넣어야 했다 (v2: 12%).
6. **임계값은 해결책이 아니다.**
   - 예시에서 놓친 라벨 127개 중 확률 0.4 이상은 15개(12%)뿐이다. 79개(62%)는 0.2 미만이다.
   - 클래스별 임계값도 이전 실험에서 효과가 작았다 (macro +0.005~0.008, micro는 하락).
7. **gate 판정 규칙(hard / 보수적 / soft)은 결과가 거의 같다** (테스트 빈 예측 35 / 34 / 34). 결과를 바꾸는 건 규칙이 아니라 데이터다.

## 5. 현재 모델 구조 (최종 조합 후보)

```
입력: 비율 유지, 짧은 변 800 / 긴 변 ≤1333
      (학습: 400~800 무작위, 반전, zoom-out 30%, 모자이크 25%, 옛날 사진 15%, 흑백 20%)
      방향 × 크기 단계별 고정 캔버스, channels_last
백본: ConvNeXt-T (ImageNet-22k, 27.8M, GELU, LayerNorm, drop path 0.1)
      stage 3 (384ch, stride 16) + stage 4 (768ch, stride 32)
헤드 (패딩 칸 제외):
      A. 마스크 0.5×(평균+최대) → 이어 붙임(1,152) → LayerNorm → Linear(28)
      B. CSRA: 칸마다 28개 점수 → 평균 + 0.3 × 클래스별 attention
      28번째 출력 = gate ("옷 입은 사람이 있나")
손실: ASL(γ−=4, clip 0.05) × 0.5 + BCE(FashionFormer 점수, shift 0.3) × 0.5 + gate BCE
데이터: Fashionpedia 43,197 + 빈 사진 10% + 사람 사진 10% (매 epoch 새로 뽑음)
최적화: AdamW 1e-4 / 1e-3, wd 0.05, clip 1, warmup 1,000, 2/3·11/12 지점 ×0.1, 18ep, EMA 0.9995
추론: 원본 + 반전 logits 평균 → 임계값 (holdout으로 선택) → gate < 0.5면 빈 라벨
파라미터: 27,854,716 (50M의 56%), 추론 약 20 ms/장 (TTA 포함, A5000)
```
