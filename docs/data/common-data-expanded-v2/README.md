# 2차 공통 외부 데이터 패키지 — 3,458장

## 먼저 볼 내용

기존 506장 전부를 유지하고 2,952장을 추가한 **외부 고유 이미지 3,458장**이다. 원본 train_inner 43,197장과 합쳐 manifest는 **46,655행**이다. 약 4,000장을 목표로 했지만 품질 기준과 승인 상한을 우선해 542장을 억지로 채우지 않았다. 확장본 학습·추론 및 Git 업로드는 실행하지 않았다.

버전: `fashion-common-expanded-partial-20261106-v2`. 이전 v1 파일은 그대로 보존했다.

## 1차와 2차 실험의 구분

- **1차:** 선별한 외부 506장을 원본 train_inner에 추가해 공통 Flip·약한 ColorJitter·가중치 샘플링·Masked BCE가 작동하는지와 소규모 추가 결과를 확인하는 실험이다. 별도 초기 flip-only 베이스라인과 비교하면 증강·샘플링 등도 바뀌므로 차이를 외부 데이터만의 효과라고 단정할 수 없다. 같은 공통 조건의 원본-only 대조 결과와 비교해야 한다.
- **2차:** 이번 3,458장 확장본을 EVA02-Small과 ConvNeXt-Tiny에 똑같이 제공해 외부 데이터 확장의 효과를 비교할 후속 실험이다. 본 패키지는 데이터 준비 결과이며 성능 개선 결과가 아니다. 데이터 양뿐 아니라 선별 구성과 규칙에 따른 가중치도 달라진다.
- 우선 각 모델에서 같은 학습 조건의 원본-only 대 외부 추가를 비교한다. 그 후 결과를 보고 BCE·ASL 또는 모델별 추가 증강을 검토한다. 지금 추가 학습이나 모델별 증강은 하지 않았다.

## 클래스 상한과 실제 선별 수

외부 데이터에서 해당 클래스가 1로 표시된 사진 수 기준이다. 한 사진이 여러 클래스에 동시에 집계되므로 합계가 고유 이미지 수와 다르다. 원본 사진 수에 더해 적용하는 총량 상한도, 증강으로 늘린 노출 수의 상한도 아니다.

| 클래스 | 1차 외부 양성 | 2차 외부 양성 | 승인 기준 |
|---|---:|---:|---|
| umbrella | 63 | 1,700 | 최대 1,700 |
| glove | 274 | 1,376 | 최대 1,700 |
| vest | 112 | 333 | 최대 600 |
| leg warmer | 54 | 54 | 품질·중복 검사 통과분 전부 |
| cape | 16 | 16 | 품질·중복 검사 통과분 전부 |
| jumpsuit | 2 | 2 | 품질·중복 검사 통과분 전부 |

전체 27개 클래스의 원본·1차·2차 양성 수 및 2차 음성·미확인 수는 `class_counts_phase1_phase2.csv`에 있다. 부족한 세 클래스는 확보량에 한계가 있어 자동 증강이나 재복사로 고유 사진 수를 부풀리지 않았다. 우산은 최종 이미지의 약 49.2%, 장갑은 약 39.8%에 양성으로 표시된다. 상한을 적용해도 균형 잡힌 데이터가 되었다는 뜻은 아니다.

**선정 이유:** 희소 클래스는 통과분을 최대한 보존하고, 확보량이 큰 우산·장갑이 외부 데이터 대부분을 독점하지 않도록 상한을 뒀다. 1,700/1,700/600은 약 4,000장 목표와 확보량을 고려한 실무 기준이며 원본 대비 비율로 계산하거나 최적으로 검증한 값이 아니다.

## 품질·중복 검사와 라벨의 한계

기술·중복 검사를 통과한 기존 9,702개 후보를 재사용했다. 원본 전체 46,780장에 대한 기존 서버 SHA-256/dHash 감사 자료를 근거로 중복 후보를 제외한 목록이며, 선택된 이미지의 SHA-256·디코딩과 원본 해시 비중복을 로컬에서 다시 확인했다. 서버 원본 이미지를 이번에 새로 전수 읽은 것은 아니다. dHash 거리 4 이하 검사가 모든 의미상 중복을 보장하지 않는다.

기존 검토 1,091장 중 채택 506장과 제외 585장의 결정을 보존했다. 새 후보 **7,193장**을 연락처 시트 형태로 시각 확인해 2,973장을 통과시켰으며, 4,220장은 대상이 불명확하거나 라벨 오류 후보·상품/삽화·과도한 의료/작업 도메인 등의 이유로 제외했다. 통과분 중 21장은 다중 라벨까지 반영한 상한 때문에 채택하지 않았다. 남은 1,418장은 모두 우산 후보이고 우산 상한에 도달해 미검토·미포함 상태다. 장갑·조끼 새 후보는 끝까지 검토했다.

이는 Codex의 축소 이미지 기반 대상 가시성·도메인 선별이며 **사람이 27개 라벨을 전수 검수한 결과가 아니다.** 세부 라벨 오류와 도메인 편향이 남을 수 있다. 이미지별 상세 제외 원인을 새로 확정한 것이 아니므로 CSV 사유는 선별 범주의 설명이다. 사람 검수가 필요하면 확대 원본과 라벨을 확인해야 한다.

외부 라벨 약 **91.53%는 -1(미확인)**이다. 미확인을 0(없음)으로 바꾸지 않았고 두 모델 모두 알려진 항목만 손실에 포함하는 **Masked BCE**를 써야 한다. 이미지 파일명·출처·라이선스·크롭 정보를 `selected_external/sources.csv`에 보존했으며 일부 비어 있는 권리 정보를 임의로 보완하거나 이용권 검증 완료로 표시하지 않았다.

## 두 모델에 공통으로 적용할 것

고정 분할 train_inner 43,197장 / holdout 2,425장 / 공식 val 1,158장을 그대로 사용한다. 외부 이미지는 train_inner에만 추가한다. holdout Macro F1으로 best/early stopping을 선택하고 공식 val은 최종 보고에만 쓴다. 클래스 순서 27개와 평가 정의를 바꾸지 않는다.

- 공통 증강: RGB/EXIF 반영 → 좌우 반전 p=0.5 → 약한 ColorJitter → bicubic 종횡비 유지 resize → 검정 중앙 padding → 각 체크포인트 mean/std.
- Jitter 범위: 밝기·대비 0.9~1.1, 채도 0.95~1.05, hue 0. 대상 그룹 확률 0.35/0.20/0이고 실제 적용 여부·계수·순서가 epoch NPZ에 저장돼 있다.
- 가중치: 기본 1.0, 중간 그룹 1.3, 합친 데이터의 양성 수 1,000 미만 클래스 1.75, leg warmer 2.5. 여러 양성 라벨은 합이 아닌 최댓값을 쓴다. 추가 sampler·shuffle·랜덤 증강을 덧붙이지 않는다.
- seed 42, replacement=True, epoch당 **43,197번 추출**, 최대 30 epoch 계획을 새로 생성했다. 고유 이미지가 늘어도 학습 step 예산은 유지되며 매 epoch 모든 이미지가 한 번씩 보이는 방식이 아니다.
- 계획상 30 epoch 외부 노출 합계는 **106,019회**다. 실제 학습 노출은 학습 종료 epoch와 실제 기록으로 확인해야 한다. `planned_class_exposure.csv`는 실행 결과가 아니다.
- 규칙은 같지만 집계가 바뀌어 원본 train_inner 중 **735행**의 최종 샘플링 가중치가 v1과 다르다. 장갑 674+1,376=2,050, 우산 114+1,700=1,814 등으로 1,000 기준을 넘는다. 데이터 양만 독립적으로 바뀐 실험이라고 표현하지 않는다.
- 모델별 입력 크기·정규화는 각 모델 설정을 유지한다(EVA 378, ConvNeXt 384). 그 전 단계의 공통 랜덤 변환은 동일하다. 결과 비교 시 입력 크기와 사전학습 등 모델 차이도 표시한다.
- accumulation에서는 전체 accumulation 구간의 알려진 라벨 수로 BCE 합을 나눈다. 배치별 평균을 단순히 accumulation 횟수로 나누면 부분 라벨에서 달라질 수 있다.

## 파일과 연결 방법

`shared-lock.json`이 이 버전의 기준이다. manifest/targets/policy/counts/30개 계획/공식 train·val 라벨 해시를 고정한다. 원본 학습·검증 이미지는 포함하지 않으므로 각자 기존 데이터 위치를 연결해야 한다. 외부 이미지는 `selected_external/images`에 있다.

EVA 기준 코드는 `feature/eva02-common-data-retrain`의 `a84528284cc8f8d2ae6177caeee67fee05b92af4`를 사용해 호환성을 검증한다. 새 패키지 경로와 이 패키지의 lock을 지정하고 실제 서버의 원본 데이터·사전학습 가중치를 사용하는 preflight는 학습 전에 별도로 실행해야 한다.

**ConvNeXt 기존 506 전용 코드에는 v1 lock과 506행 수가 고정돼 있어 패키지 경로만 바꾸면 안 된다.** 별도 제공한 `convnext_data_v2.py`는 v2 lock·46,655행을 읽는 어댑터다. 새로운 실험 코드 복사본에서 기존 `augmented_data` import를 이 어댑터로 연결하고 `original_augmentation.py`를 함께 import 경로에 둔다. 기존 506 학습 코드는 보존한다. 모델·optimizer·손실 코드 전체를 이번 패키지에 새로 통합하거나 GPU 실행한 것은 아니다.

CPU 패키지 검사: `python verify_package.py <압축을 푼 패키지 폴더>` (numpy 2.2.6, Pillow 11.3.0). 이미지 해시, 배열, 가중치, 30개 랜덤 계획의 재생성을 확인한다. 이 명령은 학습·추론을 하지 않는다.

## 검증 범위

최종 `compatibility_report.json`, `convnext_compatibility_report.json`, `delivery_verification.json`을 확인한다. EVA 원본 reader로 30개 계획, 외부 이미지의 공통 RGB 변환과 378 입력 텐서를 대조한다. ConvNeXt v2 어댑터는 30개 계획과 384 CPU 입력을 검사한다. 모델 forward, 새 GPU 학습, 서버 전체 preflight 및 재추론 완료를 뜻하지 않는다. 기존 EVA 합성 CPU 테스트 28개도 다시 실행한다.

모든 파일의 해시는 `package-files.sha256.json`, ZIP/lock 해시는 ZIP 옆 `SHA256SUMS.txt`에 기록한다. CPU 검증이 일치해도 GPU 연산·라이브러리·하드웨어 차이로 학습 결과의 완전한 결정성까지 보장하지 않는다.
