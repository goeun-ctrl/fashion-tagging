BCE 시작 식별자 `/proc/<pid>/stat`의 start_ticks=`1113513125`가 전환 전후 일치한다. BCE에 신호를 보내지 않았고 중단·재시작·checkpoint resume을 하지 않았다. 이전 순차 실행기 PID1662352에만 SIGTERM을 보내 ASL 중복 실행 경로를 없앴다. 프로세스 그룹 신호는 사용하지 않았다. 부모 종료 후 BCE는 PPID1로 계속 실행됨을 확인했다.

## 비교 조건 검증

ASL은 기존 `shared_initial_s42.pt`에서 새로 시작했다. 두 config를 비교해 loss·exp_id 외 학습 설정에 차이가 없고 initial file/model/head SHA256, source SHA256, 라이브러리 버전,18개 epoch sampler plan hash가 동일함을 확인했다. 공통 초기 파일 SHA256 `a83561ececb61894b28716994f5db54b9103f594c6330875dd5fae80959da653`도 보존됐다. 학습·평가 코어 소스는 수정하지 않았다. 새 실행기는 `scripts/parallel_role4_c1.py`다.

새 실행기는 기존 BCE 프로세스 종료 후 history1~18·epochs_run18·checkpoint·holdout 예측·summary 파일을 확인하고, ASL의 exit code0 및 같은 완료 조건도 확인한다. **양쪽을 모두 통과해야** holdout 원본/반전 평가→holdout Loss/threshold 선택→공식 val 평가→비교 보고를 시작한다. 아직 평가 단계는 시작하지 않았다. 문제가 생기면 후속 평가를 중단하며 다른 학습 프로세스를 종료하지 않는다.
