> 이 문서는 결과만 먼저 올린 것이다. 문서에 나오는 학습 코드(`experiments/role5_regularization/eva02/`, `convnext/`)와 `bootstrap_eval.py`는 아직 원격 저장소에 올리지 않았다. 지금은 로컬 브랜치 `feature/role5-regularization`에만 있다.

## 한 줄 결론

- **1단계 공통 증강(외부 506장 + 약한 색 변화 + 가중 복원 추출)만으로는 EVA02 기본 설정의 성능이 달라지지 않았다.** holdout +0.004, val −0.008이었고, 두 차이 모두 우연에 의한 흔들림 범위 안이다.
- **wd 대상 정리, drop path 0.1 단독도 기준선과 구분되지 않는다.** 모든 지표의 95% 구간이 0을 포함한다.
- **EMA 0.9995 조합(wd 제외 + drop path 0.1 + EMA)만 의미 있는 향상을 보였다.** val micro/image F1이 +0.028/+0.030이고, 95% 구간이 0을 포함하지 않는다. macro는 +0.034지만 구간이 [−0.004, +0.069]로 0에 걸쳐 있다. seed가 하나뿐이라 반복 확인이 필요하다.

### 과적합 관찰

- **모든 실행이 2~3 epoch부터 과신하기 시작한다.** train BCE는 0.004~0.015까지 내려가는데 holdout BCE는 최저점 이후 계속 오른다. 0번은 0.152에서 0.296까지, 1번은 0.306까지 올랐다.
- **BCE가 오르는 동안에도 macro F1은 10~14 epoch까지 오른다.** 임계값 0.5 기준의 F1은 확률이 과신해도 한동안 버틴다. 그래서 조기 종료가 BCE가 아닌 F1 기준이면 이 구간을 그대로 지난다.
- **drop path는 BCE 상승을 늦춘다.** ep17 기준 0.253으로 0번의 0.296보다 낮다. 다만 F1 차이로는 이어지지 않았다.
- **EMA는 BCE를 가장 낮게 유지했지만, 상승을 막지는 못했다.** 0.133에서 0.237까지 올랐다. 대신 가중치 평균이 흔들림을 줄여서 best F1이 가장 높았다.
- **wd 대상 정리는 BCE 상승을 오히려 조금 앞당겼다.** norm과 bias에 걸리던 정규화가 빠진 영향으로 보인다. 단독으로는 이득이 없다.
- AMP overflow로 건너뛴 업데이트는 실행당 7~9회(전체 약 23,000회 중)로, 학습에 영향이 없는 수준이다.

## 증강 효과가 작았던 이유

epoch 1 계획 파일(`epoch_plans/epoch_01.npz`)을 직접 집계한 값이다.

| 요소 | 실제 비중 | 기존 기준선과의 차이 |
|---|---|---|
| 좌우 반전 50% | – | 기존에도 있었음 (`FashionDataset` train=True) |
| 색 변화 (밝기·대비 ±10%, 채도 ±5%, 색조 0) | 뽑힌 이미지의 **13.3%** | 신규. 사전학습 모델이 이미 이 정도 변화에는 강함 |
| 외부 이미지 | 뽑힌 이미지의 **1.85%** | 신규. 라벨의 91%가 미확인이라, 실제 확인 라벨은 1,166개(원본의 약 0.1%) |
| 가중 복원 추출 | epoch당 고유 이미지 **27,186장** (63%) | 신규. 희귀 클래스는 자주 보지만 흔한 클래스 예시는 줄어듦 |

- 모델이 보는 데이터는 기존과 거의 같다. 과적합을 직접 줄이는 강한 증강(crop, erasing, mixup, cutmix)은 정책에서 꺼져 있다.
- 가중 추출은 초반 수렴을 빠르게 했다. ep1 holdout macro가 0.483에서 0.598로 올랐다. 하지만 최종 best에서는 차이가 사라졌고, 확률 보정은 나빠졌다 (holdout BCE 최저 0.144 → 0.152, val BCE 0.179 → 0.198).
- 외부 원본 세트(`external_merged`) 9,731장 중 검토된 것은 1,091장이고, 채택된 것은 506장이다. 정은은 단계적으로 외부 데이터를 늘릴 계획이라고 했다.

## 다음 단계 제안

1. **seed 반복**: 3번(EMA 조합)과 0번을 seed 2개씩 더 돌린다 (약 2.5시간, GPU 4장 동시). 유일하게 유의했던 결과가 seed 하나 때문인지 확인한다.
2. **EMA 단독 실행 추가**: 3번은 wd 제외 + drop path + EMA를 합친 것이다. 1·2번이 기준선과 구분되지 않았으니, 효과가 EMA에서 왔는지 "기준선 + EMA만"으로 분리한다.
3. **증강 전 데이터 + 3번 설정**: 증강 효과와 정규화 효과를 나눠서 본다.
4. **외부 데이터 2단계**: 2,000~3,000장, 전 클래스, 클래스별 상한. 바꾸는 건 외부 장수 하나만이다. 0번과 3번 설정으로 비교한다.
5. **layer decay 실험(계획의 4번)은 보류**: 1~3번 결과상 출발점은 "EMA를 포함한 설정"이 맞다. 위 1·2번을 확인한 뒤 진행한다.
6. **ConvNeXt**: `experiments/role5_regularization/convnext/`에 drop path, wd 제외, EMA 옵션 복사본을 만들어 두었다. 테스트와 학습은 아직 하지 않았다.
