기존 팀 공유 보고서는 A4 6쪽 안에서 주요 약점을 설명하기 위해 일부 하위 클래스만 본문에 제시했습니다. **본문에 없는 클래스가 모두 성능이 좋다는 뜻은 아닙니다.** 전체 27개 지표는 원래 별첨 CSV에 있었으며, 이 문서는 모든 카테고리를 읽기 쉬운 표로 풀어 쓴 추가 별첨입니다. 기존 보고서·결과는 수정하지 않았습니다.

## 표 읽는 방법

- 정답 수(Support): 해당 카테고리가 정답 라벨에 포함된 이미지 수입니다. 학습 이미지 수가 아니라 각 평가 분할의 정답 수입니다.
- Precision: 모델이 해당 카테고리라고 예측한 것 중 실제 정답인 비율입니다.
- Recall: 실제 정답인 이미지 중 모델이 찾아낸 비율입니다.
- F1: Precision과 Recall의 조화평균이며 정확도가 아닙니다.
- TP: 맞힌 양성 수, FP: 잘못 붙인 양성 수, FN: 놓친 양성 수입니다. 정답 수 = TP + FN입니다.
- 지표는 0~1이며 소수 넷째 자리로 표시했습니다. 전체 정밀도 수치는 CSV에 있습니다.
- 예측 양성이 전혀 없으면 Precision의 분모가 0입니다. 공통 평가 코드에서는 이를 0으로 기록합니다.
- 다중 라벨이므로 한 이미지에 여러 카테고리가 들어갈 수 있습니다. 클래스별 정답 수를 더한 값은 이미지 수와 다릅니다.
- 클래스 순서는 팀 공통의 0~26번 순서를 그대로 유지했습니다.

## 모든 클래스를 함께 보면 알 수 있는 점

공식 val에서 신발 F1은 0.9782(정답 804장), 드레스는 0.8912(506장), 긴바지는 0.8859(313장)입니다. 반면 레그워머 0.0000(7장), 카디건 0.0952(12장), 점프수트 0.4000(21장), 조끼 0.4118(21장), 장갑 0.5000(18장), 스웨터 0.5500(21장) 등은 상대적으로 낮습니다. 이는 이번 모델 안에서의 서술이며 다른 모델보다 우수하거나 열등하다는 비교는 아닙니다.

본문에서 다루지 않은 클래스에도 약점이 있습니다. 예를 들어 양말 F1 0.6022(정답 51장), 손목시계 0.6043(82장), 헤어 액세서리 계열 0.6571(105장), 벨트 0.6623(159장)는 레그워머·카디건만으로 설명되지 않는 개선 대상입니다.

표본이 적으면서 F1이 높은 경우도 신중히 읽어야 합니다. 공식 val의 넥타이는 정답 3장으로 TP 3·FP 1·FN 0, F1 0.8571입니다. 우산은 정답 5장으로 F1 0.7500입니다. 작은 평가 표본의 높은 수치만으로 안정적인 성능을 확정할 수 없습니다.

두 평가 분할 모두 정답 수가 0인 클래스는 없습니다. 공식 val의 레그워머는 정답이 없어서 F1이 0인 것이 아니라, 정답 7장을 모두 놓쳤기 때문에 0입니다.

클래스별 평가 표본 수와 이미지 구성이 다르므로 holdout 대비 val F1 차이가 데이터 부족이나 특정 원인 하나를 입증하지 않습니다. 학습셋의 표본 수·다양성과 혼동 원인은 별도로 확인해야 합니다. 이번 자료 정리는 기존 지표를 대조한 작업이며 추가 학습·추론은 수행하지 않았습니다.
